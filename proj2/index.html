Part 1: Fun with Filters

Part 1.1: Convolutions from Scratch!

In this section, I implemented a 2D convolution operation from scratch using both 4 nested loops and 2 nested loops (vectorized over patches). Padding was implemented using a zero-fill "same" padding strategy to maintain original image dimensions.

Code Snippets:

def conv_four(image, kernel):
    kernel = np.flip(kernel)
    ih, iw = image.shape
    kh, kw = kernel.shape
    pad_h, pad_w = kh // 2, kw // 2
    padded = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='constant', constant_values=0)
    output = np.zeros_like(image, dtype=np.float64)
    for i in range(ih):
        for j in range(iw):
            for ki in range(kh):
                for kj in range(kw):
                    output[i, j] += padded[i + ki, j + kj] * kernel[ki, kj]
    return output

def conv_two(image, kernel):
    kernel = np.flip(kernel)
    ih, iw = image.shape
    kh, kw = kernel.shape
    pad_h, pad_w = kh // 2, kw // 2
    padded_img = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='constant', constant_values=0)
    output = np.zeros_like(image, dtype=np.float64)
    for i in range(ih):
        for j in range(iw):
            patch = padded_img[i:i+kh, j:j+kw]
            output[i, j] = np.sum(patch * kernel)
    return output

Comparison with scipy.signal.convolve2d:
The custom implementation successfully mirrors the output of scipy.signal.convolve2d. However, the scipy function is highly optimized with a C backend, making its runtime orders of magnitude faster than the native Python 2-loop and 4-loop variants. For boundaries, zero-padding was manually applied to replicate the `mode='same', boundary='fill'` settings in the built-in function.

Part 1.2: Finite Difference Operator

Using the humble finite difference operators $D_x = [1, 0, -1]$ and $D_y = [1, 0, -1]^T$, I computed the partial derivatives of the cameraman image. The gradient magnitude was computed as the Euclidean norm of the $x$ and $y$ derivatives. Finally, a binarized edge image was created to suppress noise. I selected a threshold of 0.15, which I found to be the "sweet spot" that successfully suppresses the background noise on the grass and sky while retaining the sharp structural edges of the coat and tripod.

Part 1.3: Derivative of Gaussian (DoG) Filter

The standard finite difference method is highly susceptible to noise. To resolve this, I first blurred the image with a Gaussian filter before taking the derivatives. Alternatively, due to the associative property of convolutions, we can convolve the Gaussian kernel directly with $D_x$ and $D_y$ to create single-pass Derivative of Gaussian (DoG) filters. Both methods produce identical, much cleaner edges.

Part 2: Fun with Frequencies!

Part 2.1: Image "Sharpening"

The unsharp masking technique works by extracting the high frequencies of an image (by subtracting a Gaussian-blurred, low-pass version from the original) and adding a scaled amount of those high frequencies back into the original. This artificially boosts edge contrast, making it perceptually sharper. Mathematically, this multi-step process simplifies to a single unsharp mask filter via $f * ((1+\alpha)e - \alpha g)$.

Evaluation: Artificially Blurring and Re-sharpening

I took a sharp, high-quality image, blurred it artificially, and attempted to restore it. Observation: Sharpening cannot fully reconstruct the original image. The initial Gaussian blur permanently destroys the highest frequency data (fine textures and micro-edges). Re-sharpening only boosts the surviving mid-range frequencies, resulting in thick, unnatural "halos" along major structural lines rather than restoring the true original texture.

Part 2.2: Hybrid Images

Based on the SIGGRAPH 2006 paper by Oliva, Torralba, and Schyns, hybrid images exploit how humans perceive spatial frequencies at varying distances. By combining the high frequencies of one image (visible up close) with the low frequencies of another (visible from afar), the interpretation of the image changes based on viewing distance.

Part 2.4: Multiresolution Blending

Using the 1983 technique by Burt and Adelson, images can be seamlessly spliced. Instead of a harsh boundary, multiresolution blending blends high frequencies over a very narrow window and low frequencies over a wide window, resulting in a smooth transition that respects both texture and lighting.

Reflection

The most important thing I learned from this project was how powerful frequency separation is for image manipulation. While standard alpha blending causes severe ghosting and harsh edges, utilizing Laplacian stacks to treat the color data (low frequencies) independently from the structural edge data (high frequencies) allows for photorealistic compositing that handles disparate lighting scenarios beautifully.
